A 4,078-byte Python chess engine for make.fun's tiny-chess-01: 0x88 board, negamax alpha-beta with quiescence search and piece-square tables, searching a fixed 99,999 nodes per move. Practice Elo ~1200 across the three practice trials (floor 1154). Deterministic — no clock, no randomness, no model calls.

## Run it

```sh
MAKEFUN_ENV_URL=<env-url> python3 main.py
```
